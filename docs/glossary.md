# Glossary

| English | العربية | Meaning in Dynamic Cube |
|---|---|---|
| Entity | الجهة | The government ministry / authority / company owning the installation |
| Org unit | وحدة تنظيمية | Node of the configurable organization structure (sector, department, branch…) |
| Apps Control | التحكم بالتطبيقات | Configuration and user-management module |
| Class / Domain | التصنيف / القيمة | Lookup type / lookup value |
| List of values (LOV) | قائمة القيم | Registered data source and security/filter layer over classes and tables |
| Grant | صلاحية قيمة | Values (or a rule) of an LOV that a role may see |
| Data scope | نطاق البيانات | LOV grants applied to records in queries, inboxes and reports |
| Change set | مجموعة تغييرات | Configuration edits going through draft → review → approve → publish |
| Party | الطرف | Individual or establishment that applies for or holds something |
| Establishment | المنشأة | Company / office identified by CR or license |
| Delegate | المفوض | Individual authorized to act for an establishment |
| Service | الخدمة | Configured definition of something applicants can request |
| Service level / track | مستوى الخدمة / المسار | Regular (عادي), Premium (مميز), Diamond (ماسي) |
| Request | الطلب | One application instance |
| Draft | مسودة | Unsubmitted request |
| Return for correction | إعادة للاستكمال | Sending a request back to the applicant |
| Action Center | مركز الإجراءات | Employee workspace |
| Request manager | مدير الطلبات | Role that reviews and distributes requests |
| Analyst / Auditor | المحلل / المدقق | Maker / checker in a review branch |
| Issued document | المستند الصادر | Certificate, license, permit or approval |
| Certificate | الشهادة | Issued document type, e.g. classification certificate |
| Renewal | تجديد | New validity period |
| Extension | تمديد | Extends validity |
| Appeal | تظلم | Objection to a result |
| Upgrade grade | رفع الدرجة | Request a higher grade |
| Sector / field | القطاع / المجال | Classification area (construction, ICT…) |
| Grade | الدرجة | 1 (highest) to 5 |
| Technical evaluation | التقييم الفني | Staff-based scoring axis |
| Performance record | سجل الأداء | Projects-based axis |
| Governance | الحوكمة | Questionnaire-based axis |
| Credit rating | التقييم الائتماني | Financial grade from an external rating |
| Amanah | الأمانة | Municipal authority (reporting dimension) |
| Visit / inspection | زيارة / تفتيش | Field step in a service |
| Sanction | عقوبة | Penalty or ban recorded against a party |
| SLA | اتفاقية مستوى الخدمة | Target processing time on the working calendar |
