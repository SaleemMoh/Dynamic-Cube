# Working agreement

## End every response with a short summary
The owner cannot track every message and README change. Every response ends with:

```
**Summary**
- What changed (2–4 short lines, plain words).
**Your action**
- Exactly what the owner must do (pull, rebuild, run a command, decide something), or "None".
```

Keep it short and concrete: commands to copy, decisions to make, nothing else.

## Pace
The system is being reviewed part by part, starting with Apps Control, before more features are added. Do not start
new implementation until the owner agrees on the part under review.
